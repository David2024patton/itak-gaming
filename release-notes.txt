The pause menu has a new switch: Debug control. With it on, the test bench can drive the game with sent key presses, so a game can be played and checked end to end from the bench without a controller in hand, handy for testing screens a remote cannot be aimed at from here. It is off unless someone turns it on in the pause menu, it only answers the bench's sent presses, and real controllers and the TV remote work exactly as before either way. Nothing else changed: the pause lag fix, Fast-forward, the BACK popup, and the debug stats panel from 1.109 all carry over.
