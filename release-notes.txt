One engine per game now. The app used to carry a second set of game engines written in Go alongside the Rust engines that actually run your games. Those are out of the app now: Rust is the only engine inside, the app is smaller, and every future fix lands in exactly one place. The Go engines are kept on our server as a testing reference only. The sound rebuild from the last update and everything else carry over. Games and saves carry over untouched.
