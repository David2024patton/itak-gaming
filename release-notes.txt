The SNES echo now runs at the hardware's true level. Two linked fixes in the sound chip's echo path, both checked line by line against the reference DSP code. First, the echo filter now truncates every tap the way the chip does, wraps its halfway sum at 16 bits, and clamps the result, instead of accumulating in wide precision. Second, and bigger: the echo buffer write was storing every sample at twice the hardware's scale, so each echo repeat came back twice as loud and decayed half as fast as it should. On screens with strong echo feedback, like Zelda's file select, the loop fed on itself and never died away, which is the shrill ringing tone reported there. The write now stores the feedback sum at the hardware's scale with the low bit cleared, so repeats decay the way they do on a real SNES. Bench proof: the picture is bit-identical in the rain, bedroom, and doorway scenes, the rain scene's sound level is unchanged, and the file select render is now the game's own quiet music box melody under a short, natural echo. The shipping core and the Go reference core carry the same math, pinned by tests that fail on the old values. Everything else from 1.113 carries over.
